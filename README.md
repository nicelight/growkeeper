# GrowKeeper 0.2.0

Плагин ChatGPT и приватный веб-дневник для ведения растений и грядок во времени.

**Workers + D1 + R2. Без KV, собственного AI backend, React, npm runtime dependencies и vector DB.**

Это исходники частного MVP, а не уже развёрнутый сервис. Обработка изображений и reasoning происходят в ChatGPT через Skill и MCP-инструменты. Самостоятельный веб-дневник хранит и показывает данные, но не запускает LLM.

## Быстрый локальный запуск

Нужен Node.js **22.16+** с `node:sqlite`.

```bash
npm run verify
npm run dev
```

Открыть `http://127.0.0.1:8787`. Сервер выведет локальный ключ входа. Не вставлять его в ChatGPT. Данные лежат в `.local/`, фото — в `.local/r2/`. `npm install` для этих команд не нужен. После изменения кода перезапустить сервер; после изменения Skill/UI выполнить `npm run build`.

Локальный сервер использует тот же Worker-код, но адаптер Node/SQLite вместо workerd/D1. Это не доказывает совместимость с облачной средой.

## Что реализовано

- Несколько растений, постоянные UUID, предложения дружелюбных имён и переименование.
- Сохранение неразобранного текста/фото до уточнения растения. Визуальная привязка проверяется порогом и наличием подтверждённого эталона.
- Приватный фотоархив, метаданные, подбор старых кадров и возвращение реальных изображений модели.
- Наблюдения, проблемы, гипотезы, эксперименты, будущие проверки и отдельный Plant Journal.
- Атомарное закрытие Issue с единственным итогом в дневнике; различение результата, отсутствия улучшения и отсутствия данных.
- Страницы сущностей по HTTPS-ссылкам, обзор растений, фото рядом, настройки, загрузка и удаление растения.
- Browser login и OAuth code + PKCE для MCP; разделение пользователей, контроль версий и идемпотентные создания.
- Опциональный MCP Events: подписка, проверка callback, подписи, Cron, ограниченные повторы. **Выключен до настройки и проверки в реальном ChatGPT.**

## Перед реальным использованием

Прочитать `RUNBOOK.md`. Потребуются собственный Cloudflare account, D1 database ID, приватный R2 bucket, случайный `APP_SECRET`, ключ пользователя и авторизованное подключение ChatGPT. Код **не содержит** ваших ключей, облачных ресурсов или регистрации приложения.

Проект не объявляется публично готовым или прошедшим security audit. Веб-интерфейс внутри ChatGPT использует `window.openai`; универсальный bridge для других MCP Apps-хостов не реализован. При отсутствии bridge работают обычные аутентифицированные HTTPS-страницы.
