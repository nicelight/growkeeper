# UI и Worker одной версии

Сборка встраивает небольшой фиксированный набор публичных файлов (`index.html`, `app.js`, `style.css`, `widget.html`) в генерируемый JS-модуль. Worker и MCP-ресурс читают его через общий helper: код и интерфейс публикуются одним артефактом, без риска оставить старый UI при обновлении инструментов.

Список путей явный, содержимое берётся только при сборке. В runtime нет файловой системы, динамического пути или загрузки исходников. Остальные уже разрешённые маршрутизатором assets используют существующий ASSETS fallback; неизвестные HTTP-пути по-прежнему дают 404. Это не расширяет доступ к файлам.

Авторизация страниц остаётся перед выбором ассета. GET возвращает содержимое с явным Content-Type, HEAD — те же заголовки без тела. Общие security headers и no-store остаются у Worker. MCP возвращает тот же widget с прежними CSP-метаданными. Секреты и приватные данные в модуль не попадают; встраиваются только перечисленные исходные public-файлы.
