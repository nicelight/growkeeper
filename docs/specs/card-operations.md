# Изменение и удаление карточек

Изменение типа — обновление существующей карточки, не пересоздание. ID и все связанные записи остаются; связь с группой должна соответствовать итоговому типу. Вход содержит ожидаемую версию/ревизию. Нельзя тихо перезаписать параллельное изменение или угадать судьбу участников бывшей группы.

Удаление двухшаговое: чтение предпросмотра показывает точный ID/имя, тип, версию, ревизию и количества собственных фотографий/записей/версий памяти, а для группы — также участников, которые останутся без группы. После явного подтверждения пользователя исполнение принимает этот ID, точное имя, ревизию и `user_confirmed=true`. Отсутствие согласия не подразумевается из общего разрешения на уборку. Изменившийся после предпросмотра объём требует нового предпросмотра и согласования.

Исполнение использует существующий путь удаления: атомарно помечает карточку как удаляемую, блокирует новые записи и чтение медиа, удаляет R2-объекты, затем удаляет строки карточки с каскадом собственной истории. При сбое R2 оставляет tombstone; повтор с тем же ID, точным именем и явным подтверждением продолжает это уже начатое удаление. Собственная установка tombstone изменила ревизию, поэтому при продолжении она не сравнивается повторно. Новое удаление без tombstone всегда проверяет ревизию. Удаление группы не удаляет участников и их историю; удаляются только связи с группой.

Одинаковый контракт действует в чате и UI. UI показывает последствия и получает явное подтверждение; инструмент помечен destructive. Все проверки владельца остаются серверными. Каталог возможностей описывает необратимость и реальную доступность операции, не обещая восстановления после удаления.
